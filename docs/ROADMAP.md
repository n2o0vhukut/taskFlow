# 改善計画・課題（ROADMAP）

現時点の課題（抜粋）
- プランDMの説明力強化（バッジ/理由/合計/要約）。
- 重複統合の精度（正規化/しきい値/確認フロー）。
- 随時整理の導線（/organize 等）。
- ダッシュボードの期限/優先・警告の可視化。

新規課題（追記）
- チェックイン後の「適用する」DMが届かない/表示されないケースがある
  - 想定原因:
    - Interactivity の Request URL 未設定/未Verified、または Slack OFFLINE（SLACK_OFFLINE=1）
    - PREVIEW_BEFORE_APPLY=0（プレビューを無効化）
    - チェックイン経路ではなく /plan や DM自由記述経路で試している（ボタン非表示の仕様）
    - 入力結果が add/update/done/defer 0件（適用しても差分なし）
  - 対応方針:
    - 設定チェックリストを DETAIL_DESIGN/OPERATIONS に明記（Interactivity, message.im, スコープ, 再インストール）
    - プレビュー起動条件のログを強化（なぜ出さないかの根拠をDMに注記）
    - /checkin スラッシュで明示的にモーダルを開ける導線を追加（見つけやすさ）
  - 受け入れ基準:
    - 正常系: モーダル送信→プレビューDMに「適用する」ボタンが毎回表示される
    - 設定不足: DMに「設定不足の可能性（Interactivity など）」のヘルプリンクが表示される

- チェックイン入力のUXが現状不十分（自由記述中心）
  - 要望: 「現状のタスク一覧を見ながら、各タスクの進捗/状態/期日変更を直接入力」「新規タスク（タイトル/期限/優先/見積）を同時追加」
  - 対応方針（Check-in Modal v2、詳細は DETAIL_DESIGN に記載）:
    - 上位N件（例: 期限近い/doing/todo高優先）をモーダルに表示し、各行で「状態（todo/doing/done）」「期日」「（任意）所要/メモ」を編集
    - 「新規タスク追加」セクションで複数件のタイトル/期限/優先/見積を入力
    - 送信後は organize の前に v2入力を mutations として直接適用（オプションでプレビュー）
  - 受け入れ基準:
    - タスクの進捗/期日/状態がモーダルから直接更新される
    - 新規タスクがモーダルから複数件追加できる
    - 既存の自由記述も併用可（併合ロジックが競合しない）
